## ¿Para quién es este curso?

Las estructuras de datos y algoritmos (DSA) son la caja de herramientas que todo programador usa, lo sepa o no. Este curso es para ti si:

- aprendiste a programar por tu cuenta y nunca tuviste una clase formal de ciencias de la computación,
- estudias ciencias de la computación y quieres que DSA por fin te _haga clic_,
- o tienes una entrevista técnica cerca y quieres llegar con confianza.

Solo necesitas JavaScript básico: variables, funciones, bucles y arrays. Las clases las vemos juntos en el Módulo 3.

## Cómo funciona una lección

Cada lección combina tres cosas:

1. **Explicaciones cortas** en lenguaje sencillo.
2. **Animaciones** que controlas paso a paso, para que _veas_ moverse un algoritmo en lugar de imaginarlo.
3. **Código que puedes ejecutar** aquí mismo, en la página.

Probemos lo último ahora. Cambia el nombre y presiona **Ejecutar**:

```js-run
const name = 'Ada'
console.log('¡Hola ' + name + '! Bienvenido al curso.')
```

Eso es todo: sin configuración, sin instalar nada. Vas a escribir mucho código así.

Después de las lecciones, cada módulo tiene un **cuestionario** para comprobar lo que aprendiste y **ejercicios con tiempo** para practicar problemas estilo LeetCode. Pronto también tendrás un **tutor de IA** para hacerle preguntas, pedirle pistas cuando te atasques y recibir comentarios sobre tu código.

## El camino por delante

Este es el mapa, en orden:

| Parte                     | Qué vas a aprender                                                                                   |
| ------------------------- | ---------------------------------------------------------------------------------------------------- |
| **Fundamentos**           | Big O (cómo medir si tu código es eficiente), clases y punteros                                      |
| **Estructuras de datos**  | Listas enlazadas, listas doblemente enlazadas, pilas y colas, árboles, tablas hash, grafos, heaps    |
| **Recursión**             | Pensar de forma recursiva, árboles binarios de búsqueda recursivos, recorridos de árboles            |
| **Ordenamiento**          | Ordenamientos básicos (bubble, selection, insertion) y luego los eficientes: merge sort y quick sort |
| **Programación dinámica** | Resolver problemas grandes reutilizando las respuestas de problemas más pequeños                     |

Es mucho, y algunos temas asustan de lejos. Por eso cada uno está dividido en pasos pequeños, con una animación cada vez que una imagen ayuda más que las palabras.

## Al terminar el curso

- Vas a **construir** cada estructura de datos tú mismo, en JavaScript.
- Vas a explicar la **complejidad temporal y espacial** de tu código con Big O.
- Vas a **resolver** problemas de entrevista y explicar tu razonamiento en voz alta.

## Resumen

- Lecciones = explicación + animaciones + código ejecutable.
- Cada módulo termina con un cuestionario y ejercicios con tiempo.
- Empezamos por los fundamentos (Big O, clases y punteros) porque todo lo demás se construye sobre ellos.
