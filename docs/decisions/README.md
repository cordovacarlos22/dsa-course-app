# Decisions

One file per decision, so PRs never edit the same lines and can merge in any order.

- **Name:** `YYYY-MM-DD-<short-slug>.md`, e.g. `2026-10-24-quiz-modes.md`.
- **Inside:** a `#` title, then a line with the date in bold, the issue (if there is one) and who decided (and what they chose), then what was decided and why, in a few sentences.
- **Changing a decision:** add a new file that says which one it replaces. Never edit or delete an old one.

Decisions made before 2026-10-24's batch are in [`memory.md`](../../memory.md), under **Decisions**.
