# An easier Introduction: one coding warm-up

**2026-10-24** · #102, Carlos

Module 1 felt too hard for beginners. Carlos first chose "no coding checks in module 1". After a side note pointed out that students would then first press Check in Big O, he chose to keep `greet` as a warm-up. So `greet(name)` is the module's only code check, now in lesson 3, step 2 ("Printing values"), right after the Check button is explained, with the answer nearly written in the hint. All four old coding checks became predict-the-output questions: what `greet('Ana')` returns (lesson 1), the last value of a `next` chain (lesson 2), and the bug behind a `ReferenceError` and a loop that never stops (lesson 3). Every runnable example stays. The `console.log('Year:', 1995)` question that step 2 replaced moved to the module quiz (16 → 17 questions).
